# 3D建模平台

一个基于Web的功能完整的小型3D建模平台，使用Three.js + React + Node.js技术栈开发。

## 功能特性

### 核心功能
- **几何体创建**：支持立方体、球体、圆柱体、平面、圆环、圆锥等基本形状
- **模型变换**：平移、旋转、缩放操作，支持可视化变换控制器
- **多视图切换**：透视图、顶视图、前视图、侧视图四种标准视图
- **材质系统**：支持颜色调整、金属度、粗糙度等材质属性
- **光照系统**：环境光、平行光、点光源三种光源可独立开关
- **模型导出**：支持GLTF格式导出

### 用户界面
- **左侧工具栏**：快速创建各种几何体
- **中央视口**：3D场景展示与交互区域
- **右侧属性面板**：对象列表、变换控制、材质编辑、光照设置、项目管理
- **视图控制**：快速切换不同视角
- **变换控制**：底部按钮切换移动/旋转/缩放模式

### 项目管理
- 项目创建、保存、加载、删除
- 数据持久化存储
- RESTful API接口

## 技术架构

### 前端
- **框架**：React 18 + Vite
- **3D渲染**：Three.js
- **HTTP客户端**：Axios
- **端口**：3000

### 后端
- **框架**：Express.js
- **数据存储**：JSON文件持久化
- **端口**：3001

## 快速开始

### 安装依赖
```bash
npm run install:all
```

### 启动开发环境
```bash
npm run dev
```

或者分别启动：
```bash
# 启动后端服务 (端口 3001)
cd backend && npm run dev

# 启动前端开发服务器 (端口 3000)
cd frontend && npm run dev
```

### 生产构建
```bash
npm run build
npm start
```

## 使用说明

### 基本操作
1. **创建几何体**：点击左侧工具栏的图标即可在场景中创建对应的几何体
2. **选择对象**：点击场景中的对象进行选择
3. **变换操作**：选择对象后，使用底部的变换按钮切换模式，拖动控制器进行操作
4. **视图操作**：
   - 鼠标滚轮：缩放视图
   - 鼠标左键拖动：旋转视角
   - 鼠标右键拖动：平移视图
5. **属性编辑**：在右侧面板中可以精确调整位置、旋转、缩放和材质属性

### 快捷键提示
- G：移动模式
- R：旋转模式
- S：缩放模式

### 项目管理
1. 点击"新建项目"创建新项目
2. 在项目列表中点击项目即可加载
3. 点击项目右侧的×按钮删除项目

### 模型导出
1. 点击属性面板顶部的"导出 GLTF 模型"按钮
2. 浏览器会自动下载 .gltf 格式的模型文件

## API接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects | 获取所有项目列表 |
| GET | /api/projects/:id | 获取单个项目详情 |
| POST | /api/projects | 创建新项目 |
| PUT | /api/projects/:id | 更新项目 |
| DELETE | /api/projects/:id | 删除项目 |
